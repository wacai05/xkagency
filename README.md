# xkagency | Digital Architect & Brand Strategist

A high-end, premium portfolio ecosystem designed for conversion-driven digital presence. Built with a focus on cinematic motion, glassmorphism, and architectural precision.

## 🚀 Vision
Transforming complex business goals into intuitive, high-performance digital identities. This project serves as the flagship portfolio for **xkagency**, showcasing 5+ years of expertise in full-stack development and UI/UX engineering.

## ✨ Core Features
- **Cinematic Motion Engine**: Scroll-driven auto-expansion reveals and staggered text animations.
- **Dynamic Island Navigation**: A floating, morphing header that adapts to user behavior.
- **3D Spotlight Interactivity**: Mouse-tracking radial gradients and spring-animated 3D tilt cards.
- **Global Design System**: Ultra Matte Black & Cyber Violet aesthetic with persistent film grain texture.
- **Conversion-Optimized Funnel**: Global Radix UI Dialog modals for instant project inquiry from any CTA.
- **Animated Pricing Logic**: Real-time investment calculation using `@number-flow/react`.

## 🛠️ Tech Stack
- **Core**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Framer Motion
- **Components**: Radix UI, Lucide React, Shadcn UI
- **Animations**: NumberFlow, Custom CSS Noise Textures

## 📦 Getting Started

1. **Clone & Install**
   ```bash
   git clone https://github.com/wacai05/xkagency.git
   npm install
   ```

2. **Development**
   ```bash
   npm run dev
   ```

3. **Production Build**
   ```bash
   npm run build
   ```
